# Example campus-style graph for testing routing (Dijkstra) before the real
# UTK graph is ready. Made-up layout and names, not real campus data, but it
# uses every feature of the real file: big OSM-style node ids, car + walk
# edges (CW), walk-only paths (W), a one-way road, unnamed paths, two
# buildings on one node, a building only reachable on foot, and a # inside a
# building name.
#
# Format (see src/graph.cpp):
#   NODE id lat lon
#   EDGE from_id to_id length_m capacity_veh_per_hr free_flow_s mode [name]
#   BUILDING node_id name
# mode: C = cars only, W = walkers only, CW = both. W edges have capacity 0
# and free_flow 0. Every EDGE line is one direction.
#
# Layout. Letters are only for these comments; the file uses the ids:
#   A 9000000001   B 9000000002   C 9000000003   D 9000000004
#   E 9000000005   F 9000000006   G 9000000007   H 9000000008
#   I 9000000009   J 9000000010   K 9000000011   L 9000000012
#   M 9000000013
#
#     A ---- B ------- C ----- D          North Drive (top)
#     |      ^         :       |
#     |      ^ Middle  : Ped.  |          ^ = Middle Lane, one-way north
#     |      ^ Lane    : Mall  |              for cars (J -> F -> B)
#     |      ^         :       |          : = walk-only path
#     E ---- F ....... G ..M.. H          E-F = Cross Street
#     |      ^         :       |          G-M-H = unnamed footways
#     |      ^         : Steps |          G-K = Library Steps
#     I ---- J ------- K ----- L          South Avenue (bottom)
#  West Street                East Street
#
# Speeds: North Drive, East Street, Middle Lane 25 mph; South Avenue 35 mph;
# West Street and Cross Street 20 mph. Lengths are real distances between
# the coordinates (haversine), free_flow = length / speed.
#
# Expected answers. Car searches use free_flow (seconds) as the weight,
# walking searches use length (meters). Each answer is the unique best path
# (no ties).
#
#   Car, Stadium (I) to Student Union (B):
#       I -> J -> F -> B
#       9000000009 9000000010 9000000006 9000000002
#       30.2 s
#   Car, I to B, avoiding Middle Lane:
#       I -> E -> A -> B
#       9000000009 9000000005 9000000001 9000000002
#       36.3 s
#   Car, B to J (Middle Lane is one-way the wrong way):
#       B -> A -> E -> I -> J
#       9000000002 9000000001 9000000005 9000000009 9000000010
#       45.9 s
#   Walk, B to J (walkers can use Middle Lane southbound):
#       B -> F -> J
#       9000000002 9000000006 9000000010
#       230.8 m
#   Walk, Student Union (B) to Library (M):
#       B -> F -> G -> M
#       9000000002 9000000006 9000000007 9000000013
#       348.7 m
#   Car, I to Library (M): M only has walk edges:
#       no path
#   Walk, J to C (cuts across on the footway and Pedestrian Mall):
#       J -> F -> G -> C
#       9000000010 9000000006 9000000007 9000000003
#       371.0 m
#   Car, J to C (same trip by car):
#       J -> F -> B -> C
#       9000000010 9000000006 9000000002 9000000003
#       35.8 s
#   Walk, E to Art Museum (H) (unnamed footways past the Library):
#       E -> F -> G -> M -> H
#       9000000005 9000000006 9000000007 9000000013 9000000008
#       458.2 m
#
